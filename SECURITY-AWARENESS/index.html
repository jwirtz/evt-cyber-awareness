Here's the part that should sting a little

1

Read the address, not the shape

That link went to EVTC0RP.COM, with a zero where EVTCORP.COM has an O. The all caps hid the swap. That one character is the whole trick behind a lookalike domain.

2

Notice the vague ask

"For more information, click here" with no detail is exactly how a bad link gets clicked. Ask yourself where it actually goes and why.

3

When in doubt, ask us

A 30 second message to the security team beats a 30 day incident. We never mind the question.

If this had been the real thing

Clicked something sketchy, entered a password somewhere odd, or approved an MFA prompt you didn't start? Tell the EVT security team right away. We can kill your sessions in minutes, but only if we know.
